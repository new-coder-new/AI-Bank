# 意图识别与字段抽取测试用例

本套用来自测「用户一句话 → 细分模块定位 → 关键字段抽取」的能力，覆盖 8 个业务域、18 个细分模块。

## 运行方式

```bash
node tests/intent-suite.js        # 控制台表格 + 通过率
node tests/intent-suite.js --md   # 输出 Markdown 表格（便于贴报告）
```

- 测试直接加载 `js/guide.js`（对话向导层），用本地规则跑，**不依赖网络与 API Key**
- UI 与后端接口用桩替代（`appendMessage` / `addTransaction` / `showBillOverview` 等），只校验「路由 + 字段」
- 每个用例可多轮（`steps` 数组），逐条发送后读取 `GUIDE_*` 会话状态判定

## 判定口径

| 维度 | 判定方式 |
|---|---|
| 模块定位 | 是否创建了对应会话：`GUIDE_TRANSFER` / `GUIDE_AA` / `GUIDE_WEALTH` / `GUIDE_CARD_APPLY` / `GUIDE_CARD_LIMIT` / `GUIDE_TXN_LIMIT` / `GUIDE_CARD_LOST` / `GUIDE_SUB`，或调用了对应只读渲染（账单分析 / 异常交易 / 风险评估 / 持仓） |
| 字段抽取 | 转账：`kind`（name/phone/timed）、`payee`、`phone`、`amount`、`date`、`time`、`repeat`；AA：`total`、`participants`；理财：`product`、`amount`；卡片申请：`cardType`、`limit`、`purpose`；额度调整：`card`、`limit`、`reason`、`stage`；交易限制：`single`、`daily`；挂失：`card.tail`；订阅：`mode`、`preset`、`cycle`、`target`、`newAutoRenew` |
| 反例 | 无关内容不得进入任何业务流；残缺指令（如「给张三转」）不得报错 |

## LLM 版评测（硅基流动 Qwen）

```bash
node tests/llm-intent-suite.js
```

- 模型：`Qwen/Qwen3-30B-A3B-Instruct-2507`（硅基流动，可在 `SILICONFLOW_MODEL` 覆盖）
- Key：读取 `js/config.local.js`（已 git 忽略）
- 做法：把句子丢给模型，要求输出 `{module, 字段...}`，再与预期比对，统计意图准确率与字段准确率
- 用例：23 条，覆盖全部 15 个细分模块 + 1 条无关输入反例

### 最近一次结果

| 指标 | 结果 |
| --- | --- |
| 意图准确率 | 23/23（100%） |
| 字段准确率 | 28/28（100%） |
| 整体通过 | 23/23 |

### 评测中暴露并已修正的模型问题

| 句子 | 初始问题 | 处理 |
| --- | --- | --- |
| 明天下午6点转账给张三111 | 金额 111 漏抽 | 提示词补充「金额可能紧跟收款人」规则 |
| 某度网盘年卡不续费了 | 误判为 sub.cancel | 提示词补充「不续费/关闭续费 → sub.renew」规则 |
| 我要设置单笔限额20000，每日限额50000 | single/daily 未输出 | 字段清单补充 single、daily |
| 我想要订阅某易云年卡 | service 返回「某易云年卡」 | 周期归一化（年卡 → /年），断言改为包含匹配 |

> 两组套件互补：`intent-suite.js` 测本地规则层（离线、确定性），`llm-intent-suite.js` 测模型层（有大模型 Key 时）。

## 按钮枚举层（省钱 & 稳定）

设计约定：**按钮 = 状态校验层**，点击直接把固定枚举写进会话状态，不经过模型；只有「用户打字且本地规则认不出」时才调用模型。

| 路径 | 是否调用模型 | 说明 |
| --- | --- | --- |
| 点按钮（【每天】【是】【否】【CARD-2】【允许】等） | 否 | 固定枚举直传，如 `guideTimedRepeatChoose('每天')`、`guideTransferRemarkChoice(false)` |
| 打字回答（每天 / 是的 / 可以） | 本地规则优先 | 命中枚举词表直接落库；认不出才调模型 |
| 打字且完全没命中 | 是 | `guideAISlots` → Qwen 抽取；无 Key 时降级为 null |
