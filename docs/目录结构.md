## 约定

1. **源码与产物**：仓库**只保留 `.ts` 源码**，`.js` 由 `npm run build:ts` 生成（已加入 `.gitignore`）；`npm start` / `npm test` / Docker 构建都会先自动编译，容器内也执行一次 `npm run build:ts`。
2. **类型门禁**：`npm run typecheck` = 主检查 → 全项目 strict → 严格 emit，三步全过才算通过。
3. **测试门禁**：`npm test` 串联 8 个套件；`server-suite` 自起临时端口与临时数据库，不依赖本地服务。
4. **数据目录**：`data/` 不入库；生产用数据卷挂载到 `/app/data`，`BANK_DB_FILE` 可覆盖路径。
5. **密钥**：`js/core/config.local.js` 不入库；容器内用环境变量注入。
