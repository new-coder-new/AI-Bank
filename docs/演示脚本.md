# 智银管家 · 5 分钟手机演示脚本（精简版）

> 适用：手机录制，竖屏。
> 访问地址：`http://<电脑局域网IP>:8787/`（录制前用 `/api/health` 自测）
> 演示验证码 / 交易密码统一为 `123456`；录制前先点右上角头像 →「重置演示数据」。

## 一、录制前 3 分钟检查

| 项 | 动作 |
|---|---|
| 网络 | 手机与电脑连同一个 Wi-Fi/热点，浏览器打开局域网地址 |
| 数据 | 头像 → 重置演示数据 → 刷新页面 |
| 环境 | 勿扰模式、关后台 App、亮度调高、电量 > 50% |
| 输入 | 把下面 6 句话存进手机备忘录，录制时逐条复制粘贴 |
| 构图 | 竖屏；输入完点键盘「完成」再操作 |

## 二、逐秒分镜（共 5 段，约 4 分 40 秒）

| 时间 | 操作 | 输入（粘贴） | 画面预期 |
|---|---|---|---|
| 0:00–0:25 | 停在主菜单 | — | 六个入口 + 今日提醒 |
| 0:25–1:05 | 点「转账收款」 | `给张三转账 800 元` | 二级菜单 → 备注询问 → 确认卡 → 确认执行 → 成功卡（T1 免验证） |
| 1:05–1:50 | 继续同一模块 | `明天下午3点转账给张三1000元` | 定时确认卡 → 输入 `123456` → 验证并执行 → 创建成功 + 收尾问句 |
| 1:50–2:35 | 说「退出」，点「账单与交易」 | `退出` → `分析账单` | 账单卡：收支、支出构成、趋势；点「本年」再点回「本月」 |
| 2:35–3:25 | 点「理财」 | `申购1001，5000元` | （如首次）风险测评 → 确认卡 → 短信验证 → 持仓更新 |
| 3:25–4:10 | 点「订阅管理」 | `查看我的订阅` → `订阅某视频平台VIP年卡` | 我的订阅列表；重复订阅被拦截提示 |
| 4:10–4:40 | 头像 → 重置演示数据 | — | 数据恢复初始 |
| 4:40–4:50 | 收尾定格 | — | 主菜单画面 |

> 时间紧：删掉 3:25–4:10 订阅段，就是 4 分钟短版。

## 三、旁白台词（每段一句，可直接念）

1. 「这是智银管家，一个对话式银行服务台：主菜单只负责选模块，进入模块后再说需求。」
2. 「800 元属于小额档，确认卡点执行就能完成，不需要额外验证。」
3. 「1000 元进入短信验证档，所以这里要输验证码 123456。」
4. 「账单分析支持本月和本年的切换，这是支出构成和支出趋势。」
5. 「理财申购会先看风险测评结果，金额越大验证等级越高，全程有确认卡。」
6. 「订阅管理能看到我现有的会员，重复订阅会被直接拦下来。」
7. 「所有数据都能一键恢复成初始演示状态。」

## 四、录制技巧

- 每次输入后停 1.5–2 秒，等回复渲染完再点下一步
- 鼠标/手指操作放慢，便于后期剪辑
- 出错就按「退出」回主菜单，或点「重置演示数据」重来
- 键盘会挡住对话：输入完先收起键盘
- 旁白可边录边说（开麦克风），也可静音录屏后配音 + 自动字幕

## 六、自动录制（Playwright）

不想手动录时，用内置脚本自动跑完整流程并出片：

```bash
npm run demo:record              # iPhone 13 设备模拟，约 5 分钟，输出 preview/demo/demo-<时间>.mp4
npm run demo:record:android      # Pixel 7（Chromium）模拟
npm run demo:check               # 快速自检：约 1 分钟，只验证 6 步是否都通过
node scripts/auto-demo.mjs --pace=2.2 --fps=4 --keep-frames   # 自定义节奏 / 帧保留
```

脚本覆盖 6 个步骤并逐步断言：

1. 转账 800（T1 密码验证）
2. 定时转账 1000（T2 短信验证码）
3. 账单分析（本月 ↔ 本年）
4. 理财申购 5000（确认卡 + 短信验证）
5. 我的订阅
6. 重复订阅拦截

录完打印 `[结果] … ✅`；视频为竖屏 1170×1992（iPhone 13 的 3x 视口），时长约 4 分 50 秒。

依赖：`playwright`（用系统 Chrome，无需下载浏览器）+ `@ffmpeg-installer/ffmpeg`（合成 mp4）。
