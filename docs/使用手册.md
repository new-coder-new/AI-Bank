## 三、对话总规则（重要）

### 3.1 主菜单：只认模块，不直接办业务

```
主菜单说「转账」          → 打开转账二级菜单
主菜单说「给张三转账1000元」→ 同样只打开转账二级菜单（不再直通）
主菜单说「有哪些理财产品」  → 打开理财二级菜单（清单要在模块内问）
```

例外：**只读查询**仍然直接出结果 —— 「查余额 / 查信用卡额度 / 看交易记录」。

### 3.2 模块作用域：进哪个模块就只办哪个模块的事

```
在「卡片管理」里说「我不想订阅某易云了」
→ 当前在卡片管理，不能直接办理订阅管理业务。
  回复「退出」回到主菜单，或说「切换到订阅管理」。
```

- 说「切换到 XX」→ 直接打开对方模块菜单（不抽槽位）
- 说「退出」→ 回到主菜单卡片
- 只读查询、帮助类问题不受拦截

### 3.3 三类收尾都会问「还要继续吗」

一笔业务无论 **完成 / 取消 / 退出**，都会统一询问：

```
还需要办理其他转账业务吗？
如无需办理，请回复「退出」。
```

| 你的回复 | 结果 |
|---|---|
| 需要 / 要 / 继续 / 好的 | 打开该模块二级菜单 |
| 退出 / 不用了 / 不需要 / 算了 | 回到主菜单卡片 |
| 直接说本模块业务（如「给李四转200」） | 直接继续办理 |
| 说别的模块 | 按模块作用域拦截提示 |

### 3.4 确认卡是硬拦截

停在确认卡（转账确认、挂失确认、申购确认等）上时，说别的话只会得到：

```
请完成上述操作。
```

点【取消 / 暂不执行】= 视为完成一次业务（会进入 3.3 的询问）。

### 3.5 点选项后的统一记录

点任意「是 / 否」类按钮后，问题会保留并追加所选：

```
是否开启自动续费？
是否开启自动续费：是
```

## 四、转账

### 4.1 姓名转账

| 步骤 | 示例 |
|---|---|
| 发起 | 「给张三转账1000元」或「向张三转账」 |
| 问金额 | 只说人名时会追问「麻烦告诉我转账金额」 |
| 备注 | 「是否需要添加备注？」点是否，或直接说备注内容 |
| 确认 | 「确认向张三转账1000元，请确认」→ 确认卡 |
| 完成 | 转账完成卡（金额 / 收款方 / 余额）→ 询问是否继续 |

要点：
- 收款人必须是**通讯录联系人**（林小雨 / 张三 / 李四 / 王五 / 陈爸爸 / 陈妈妈）
- 金额支持中文数字与单位：「一千五」「1.5万」「100百万」「1个亿」
- 金额必须大于 0，负数会提示重新输入
- 只缺金额时，任何听不懂的输入都会重复「麻烦告诉我转账金额」

### 4.2 手机号转账

「转账给13800138000」→ 补金额 → 备注 → 确认。

### 4.3 定时转账

「明天下午3点转账给张三」→ 金额 → 时段不明确时会问「请问 2026-11-03 下午几点执行？」→ 是否重复（不重复/每天/每周/每月/每年）→ 创建定时任务（需验证码）。

### 4.4 AA 收款

```
「我和张三AA，我垫了600元」
→ 还有其他参与人吗？
→ 没有
→ 确认卡：垫付总额 ¥600 / 2 人（含我）/ 每人 ¥300
```

- 自己不用写进名单（「我」会被自动忽略）
- 「没有了 / 就这些 / 够了」都能结束名单
- 名单里若有非通讯录姓名会提示可选联系人

## 六、卡片管理

| 功能 | 示例说法 | 说明 |
|---|---|---|
| 卡片申请 | 办一张金卡，额度5万 | **两段式**：先收卡种+额度，再单独问主要用途 |
| 我的卡片 | 查看我的信用卡 | 卡片列表与额度 |
| 额度调整 | 白金卡额度提到8万 | **两段式**：先目标额度（附当前/最低），再问调整原因 |
| 交易限制 | 6789的卡，单笔限额2万 | 单笔/每日限额，可只改一项（另一项说「不变」） |
| 卡片挂失 | 挂失尾号6789的卡 | 直接出确认挂失卡（需验证），挂失后卡片不可用 |

可选枚举：
- 卡种：白金信用卡 / 标准金卡 / 旅行信用卡 / 青年卡
- 用途：日常消费 / 出行差旅 / 教育培训 / 大额购物 / 其他
- 调额原因：消费需求增加 / 收入提升 / 信用记录良好 / 主动降低额度 / 长期不用 / 风险控制 / 其他

枚举答不上来时，会一直重复提问并列出可选项。

## 七、理财

### 7.1 申购

```
「申购1001，5000元」或「申购稳健增利90天 5000元」
→ 风险测评有效 → 确认申购卡
→ 完成 → 询问是否继续
```

- 产品固定四位编号：1001 稳健增利90天 / 1002 天天盈货币基金 / 1003 均衡配置混合基金 / 1004 安享三年定期 / 1005 成长先锋股票基金
- 申购前需有效风险测评（有效期 1 年），过期会引导重新测评
- 金额低于起购额会提示（如「申购金额不能低于起购金额 ¥1000」）

### 7.2 在售产品清单（模块内）

```
理财 → 有哪些理财产品 / 能买什么基金 / 产品清单
→ 在售理财产品（共 5 支）
  默认收起：展示推荐 3 款 + 「展开更多 2 款产品」
```

### 7.3 风险测评 / 持仓管理

- 「做一次风险测评」→ 进入测评
- 「查看持仓收益」→ 持仓列表；可赎回全部或指定产品赎回

## 八、订阅管理

### 8.1 菜单

```
订阅管理包含这些操作
 添加订阅   例如：我想要订阅某易云年卡
 取消订阅   例如：取消所有订阅
 管理自动续费 例如：某度网盘年卡不续费了
 可订阅会员  例如：能订哪些会员
```

### 8.2 添加订阅

「订阅某易云年卡」→ 选择扣费周期（月/季/年）→ 是否开启自动续费 → 确认新增订阅卡 → 完成。

- 可订阅服务：某易云 VIP / 某讯 VIP / 某度网盘 VIP（月/季/年三档价格）

### 8.3 取消与续费

- 「取消所有订阅」→ 一键全取消确认卡（列出全部待取消项）
- 「取消订阅」→ 列出有效订阅，点/说选一项
- 「某度网盘不续费了」→ 管理自动续费（关闭）
- 已订阅项在「可订阅会员」清单里会标「（已订阅）」

## 九、生日鲜花

> 入口：仅保留主菜单「今日提醒」生日行的【订鲜花+蛋糕】按钮；主菜单按钮、节日提醒按钮、「查看生日联系人」按钮均已暂时屏蔽。

### 9.1 菜单

```
生日鲜花包含这些操作
 订鲜花+蛋糕   例如：给林小雨订一束花
 查看鲜花订单  例如：查看鲜花订单
 生日提醒     例如：最近谁的生日
```

### 9.2 资金预留（自动）

- 只要**通讯录联系人的生日在本月**，系统会在启动时按**人数逐一锁定**活期（每人 ¥1000，各一笔冻结记录）：
  - 可用余额 −1000，冻结金额 +1000，并在「今日提醒」里显示「已为生日鲜花预留 ¥1000（可用余额已扣减，YYYY-MM-DD 自动解冻）」
  - 释放日期 = 当月最后一天，到期自动解冻回到可用余额
  - 同一月份只锁一次

### 9.3 下单

「给林小雨订一束花」→ 确认鲜花订单卡（收花人 / 联系电话 / 收货地址 / 花束款式 / 配送日期 / 时段 / 贺卡）→ 提交时走安全验证。

- 收花人可来自通讯录，也可直接说名字
- 可改单（换款式补差价）、取消订单（待配送状态）
- 今日提醒里的生日/节日条目可直接点「订鲜花+蛋糕」「订情人节鲜花」「订母亲节鲜花」「订父亲节鲜花」
- 主菜单不再展示「生日鲜花」入口按钮（功能未下线，用语音/文字进入）

### 9.4 订单

「查看鲜花订单」→ 待配送 / 已完成列表；在列表里可说「取消李四的鲜花订单」。

## 十一、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 说业务却只弹出菜单 | 主菜单规则：先选模块，进入后再办事 |
| 提示「当前在 XX，不能直接办理 YY」 | 模块作用域隔离；回「切换到 YY」或「退出」 |
| 一直回「请完成上述操作」 | 有未处理的确认卡；点确认/取消，或说「退出」 |
| 说「退出」回到主菜单卡片 | 收尾询问阶段的退出；流程中途退出也会先问是否继续 |
| 订花没进入下单 | 需先进入「生日鲜花」模块；主菜单只会打开模块菜单 |
| 卡额度/限额/用途答非所问 | 枚举类问题会重复提问并列出可选项 |
| 数字被当成产品编号 | 编号 1001–1005；单说「1001」按金额处理，编号请说「编号1001」或「1001 5000」 |

```
账户总览 / 基本信息 / 卡片信息 / 复核审批 / 交易记录 / 联系人
```

## 十三、术语

| 术语 | 含义 |
