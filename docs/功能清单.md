## 二、服务面板：5 大类 18 项

对应实现：`js/core/ui.ts` 的 `FUNC_GROUPS`，点击后进入 `js/flows/guide-*.ts` 的逐步引导流程。

### 1. 转账（4 项）

| 功能 | 交互 | 实现 |
|---|---|---|
| 姓名转账 | 问姓名 → 问金额 → 确认卡 → 分级验证 | `guide-transfer.ts` / `transfer.ts` |
| 手机号转账 | 问手机号 → 金额 → 确认卡 → 验证 | 同上 |
| 定时转账 | 姓名 → 金额 → 日期 → 时段 → 重复规则 → 验证；到期自动执行，执行前可取消 | 同上 |
| AA 收款 | 总额 → 参与人（可多人）→ 均摊 → 确认卡 | 同上 |

**金额分级验证**（`js/agent/agent.ts` 的 `AGENT_TRANSFER_TIERS`）：

| 档位 | 金额 | 验证方式 |
|---|---|---|
| T1 | < ¥1,000 | 确认卡 + 指纹/密码 |
| T2 | ¥1,000 – 1 万 | 确认卡 + 短信验证码 |
| T3 | ¥1 万 – 10 万 | 确认卡 + 短信 + 人脸 |
| T4 | ≥ ¥10 万 | 确认卡 + 短信 + 人脸 + 人工复核 |

风险可疑度会提升档位（高风险至少 T3、中风险至少 T2），最终取「金额档」与「可疑度档」中更严的一档。

### 2. 账单（2 项）

| 功能 | 内容 | 实现 |
|---|---|---|
| 账单分析 | 本月/本年收支统计、分类占比环形图、趋势图、财务报告 | `analysis.ts` |
| 异常交易 | 大额、深夜、异地等可疑交易识别与提示 | `analysis.ts` / `riskdetect.ts` |

### 3. 卡片（5 项）

| 功能 | 内容 | 实现 |
|---|---|---|
| 卡片申请 | 卡种 → 额度 → 用途 → 确认，提交后进入复核 | `guide-card.ts` / `cardlimit.ts` |
| 我的卡片 | 卡片列表、卡面、额度与状态 | `card.ts` |
| 额度调整 | 选卡 → 目标额度 → 调整原因 → 复核审批 | `cardlimit.ts` |
| 交易限制 | 单笔限额、每日限额设置 | `cardlimit.ts` |
| 卡片挂失 | 按卡尾号定位 → 挂失确认 → 状态更新 | `cardservice.ts` |

### 4. 理财（3 项）

| 功能 | 内容 | 实现 |
|---|---|---|
| 产品申购 | 风险测评前置 → 产品选择 → 金额 → 确认（≥1000 需验证令牌） | `guide-wealth.ts` / `wealth.ts` |
| 风险评估 | 风险承受能力问卷 → 评级结果 | `wealth.ts` |
| 持仓管理 | 持仓列表、收益、**赎回 T+1 到账**（提交记在途，次日入账） | `wealth.ts` |

### 5. 生活（2 项）

| 功能 | 内容 | 实现 |
|---|---|---|
| 订阅管理 | 清单、月度均摊、添加订阅（首次扣费）、取消、自动续费开关 | `guide-sub.ts` / `subscription.ts` |
| 生日鲜花 | 表单卡一次填完：花束/蛋糕、收花人、地址、送达日期时段、贺卡 → 确认 → 验证 | `guide-flower.ts` |

## 五、数据与安全

| 项 | 实现 |
|---|---|
| 会话鉴权 | `POST /api/session` 签发 48 位令牌，12 小时有效，写接口需 `X-Bank-Session` |
| 同源校验 | `isSameOriginStrict`，无 Origin 且无 Referer 直接拒绝 |
| 密钥隔离 | 前端恒为 `window.__BANK_KEYS__ = {}`，模型调用走 `/api/ai/chat` 服务端代理 |
| 资金门禁 | 所有扣款统一收口到 `addTransaction`，余额不足直接拦截 |
| 幂等 | 转账支持 `idempotencyKey`，重复提交返回 `duplicate:true` 不二次扣款 |
| 令牌换取去重 | `API.verifyPending` 防止重复弹验证码 |
| 频控 | 资金类接口同 IP 每分钟 20 次 |
| 审计 | `ledger` 表记录资金动作，`GET /api/audit` 查询 |
| 敏感信息 | 客户信息页支持遮罩切换 |
