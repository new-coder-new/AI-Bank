# 智银管家 · 全模块演示方案（覆盖所有功能）

> 目标：**每个模块的每一项都出现一次**。
> 建议拆成 3 集（单集 4–5 分钟），也可以合成一条约 15 分钟的完整版。
> 通用规则：每一步之间停顿 **≤2 秒**（上一条视频停顿过长的反馈）；每集开始前「重置演示数据」；破坏性操作（挂失 / 取消订阅）放在每集最后。

## 覆盖清单（可当验收表）

| 模块 | 必须出现的功能 |
|---|---|
| 转账收款 | 姓名转账 / 手机号转账 / 定时转账 / AA 收款 |
| 账单与交易 | 账单分析（本月 + 本年）/ 异常交易 |
| 卡片管理 | 我的卡片 / 卡片申请 / 额度调整 / 交易限制 / 卡片挂失 |
| 理财 | 我的持仓 / 在售产品清单 / 产品申购 / 风险评估 |
| 订阅管理 | 我的订阅 / 可订阅会员 / 添加订阅 / 管理自动续费 / 取消订阅 |
| 生活订购 | 生日鲜花（订鲜花+蛋糕 / 查看鲜花订单 / 生日提醒） |
| 更多入口 | 银行卡转账 / 转账记录 / 批量转账 / 账单分期 / 复核审批 / 安全中心 |
| 用户信息页 | 账户总览 / 基本信息 / 卡片信息 / 复核审批 / 交易记录 / 联系人 |
| 智能体 | 多步指令 / 消费决策 / 目标规划 / 知识问答 / 财务体检 |
| 安全体系 | T1 密码指纹 / T2 短信 / T3 短信+人脸 / T4 人工复核 |
| 其他 | 一键重置演示数据 / 深色模式 |

## 第 1 集：转账收款 + 安全分级（约 4 分 30 秒）

| 时间 | 模块 | 输入 / 操作 | 画面要点 |
|---|---|---|---|
| 0:00–0:15 | 开场 | 停留主菜单 | 六个入口 + 今日提醒 |
| 0:15–1:20 | 姓名转账（T1） | `给张三转账 700 元` → 备注「否」→「确认转账」→ 密码 123456 | 确认卡 → 密码弹窗 → 转账已完成 |
| 1:20–2:10 | 手机号转账（T2） | `转账给13800138000，1200元` → 备注否 → 短信 123456 | 短信验证档位提示 |
| 2:10–3:10 | 定时转账（T3） | `明天下午3点转账给张三20000元` → 不重复 → 备注否 → 短信 + 人脸 → 确认 | 短信+人脸两段验证，创建成功 |
| 3:10–3:35 | AA 收款 | `我和张三AA，我垫了600元` → `没有了` → 发起 | AA 确认卡 → 完成卡 |
| 3:35–3:55 | 安全中心 | 头像 → 复核审批 / 安全中心 | 展示验证设置入口 |
| 3:55–4:05 | T4 人工复核 | `给张三转账120000元` → 短信+人脸 → 提交复核 | 「已提交人工复核，账户未扣款」 |
| 4:05–4:20 | 收尾 | 回主菜单 | 一句话总结 |

> 说明：T4 也可以放在第 2 集的「复核审批」里审批通过，形成闭环。

## 第 2 集：卡片 + 理财 + 订阅 + 鲜花（约 4 分 50 秒）

| 时间 | 模块 | 输入 / 操作 | 画面要点 |
|---|---|---|---|
| 0:00–0:15 | 开场 | 点「卡片管理」 | 五项菜单 |
| 0:15–0:30 | 我的卡片 | `查看我的信用卡` | 卡列表、额度、已用 |
| 0:30–1:15 | 卡片申请 | `办一张金卡，额度5万` → 用途「出行差旅」→ 确认 → 验证 | 两段式：卡种+额度 → 用途 |
| 1:15–1:45 | 额度调整 | `白金卡额度提到8万` → 原因「消费需求增加」→ 确认 | 调额确认卡 |
| 1:45–2:05 | 交易限制 | `尾号6789的卡，单笔限额2万` → 另一项「不变」 | 单笔/每日限额 |
| 2:05–2:25 | 卡片挂失 | `挂失尾号6789的卡` → 确认（验证） | 挂失后状态（破坏性，放最后） |
| 2:25–2:40 | 我的持仓 | `查看我的持仓` | 持仓总金额、收益、产品行 |
| 2:40–2:55 | 在售产品清单 | `有哪些理财产品` | 清单 + 起购金额 |
| 2:55–3:40 | 产品申购 | `申购1001，5000元` → 风险测评 → 确认 → 短信 | 测评结果 + 确认卡 + 持仓变化 |
| 3:40–4:00 | 风险评估 | `做一次风险测评` | 结果等级与有效期 |
| 4:00–4:10 | 我的订阅 | `查看我的订阅` | 名称・周期・下次扣款 |
| 4:10–4:20 | 可订阅会员 | `能订哪些会员` | 四档价格表 |
| 4:20–4:35 | 添加订阅 | `订阅某视频平台VIP年卡` → 自动续费「否」→ 确认 | 新增订阅卡 |
| 4:35–4:50 | 管理自动续费 | `关闭某阅读APP会员的自动续费` | 续费状态切换 |
| 4:50–5:05 | 取消订阅 | `取消所有订阅` → 确认 | 一键取消（破坏性，放最后） |
| 5:05–5:45 | 生日鲜花 | 主菜单「今日提醒」→ 订鲜花+蛋糕 → 收花人/花束/日期 → 确认 | 订单确认卡 |
| 5:45–6:00 | 鲜花订单 | `查看鲜花订单` | 订单列表 |

> 本集偏长，可拆成「卡片 / 理财+订阅+鲜花」两条各 3 分钟。

## 录制建议

| 项 | 建议 |
|---|---|
| 节奏 | 每步操作之间 **1–2 秒**；模块切换后停 3 秒即可（不要 10 秒以上空镜） |
| 顺序 | 每集开头「重置演示数据」；破坏性操作（挂失/取消订阅/取消全部）放每集末尾 |
| 验证码 | 统一 `123456`（短信、交易密码） |
| 理财 | 若想跳过 5 题测评，可先做一次测评再录；或在「申购」段展示测评结果页 |
| 自动录制 | 现有 `scripts/auto-demo.mjs` 覆盖精简版 6 步；需要全模块版可在其基础上按上表追加段落 |

## 时长换算

| 版本 | 时长 | 适用 |
|---|---|---|
| 精简版（现有脚本） | 约 3–5 分钟 | 一次性演示、投屏 |
| 本方案 3 集 | 约 4:30 / 4:50 / 5:20 | 系列短视频、分模块讲解 |
| 全模块单条 | 约 15 分钟 | 完整验收、存档 |
