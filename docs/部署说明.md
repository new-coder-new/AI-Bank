# 部署说明

## 1. 环境要求

| 项 | 要求 |
|---|---|
| Node.js | ≥ 22（使用内置 `node:sqlite`，无需编译原生模块） |
| 操作系统 | Windows / Linux / macOS 均可 |
| 端口 | 默认 `8787`（`PORT` 环境变量可改） |
| 浏览器 | Chrome / Edge / Safari 现代版本 |

## 2. 本地运行

```bash
# 1) 安装依赖（仅构建期依赖，运行时零第三方依赖）
npm install

# 2) 首次会编译 TypeScript 到 build/js，再启动服务
npm start
# 或开发模式（Vite HMR）
npm run dev
```

启动后访问 `http://127.0.0.1:8787/`，健康检查：`GET /api/health`。

## 3. 构建

```bash
npm run build      # tsc 编译 38 个 TS 脚本 + vite 打包
npm run typecheck  # 三套 tsconfig 全量类型检查（strict）
npm test           # 10 个测试套件
```

产物：

- `build/js/**`：由 `js/**/*.ts` 编译得到，`index.html` 直接引用；
- `dist/`：Vite 打包产物（可选，Docker 中未使用）。

## 4. Docker

```bash
docker build -t zhiyin .
docker run -p 8787:8787 -v $(pwd)/data:/app/data zhiyin
```

- 镜像基于 `node:22-alpine`，构建阶段执行 `npm ci` 与 `npm run build:ts`；
- 数据目录 `data/` 建议挂载卷，内含 `bank.db`（SQLite，WAL 模式）。

## 5. 云服务器（CVM）一键部署

```bash
bash scripts/deploy-cvm.sh
```

脚本会：本地编译 TypeScript → 打包（含 `build/`，排除 `data/`、`node_modules/`、本地密钥）→
`scp` 上传 → 解压（**保留服务器上的 `data/` 目录**）→ `systemctl restart` → 健康检查。

使用前在脚本顶部确认 `HOST`、`APP_DIR`、`SERVICE`、`PORT` 四项。

服务器侧需要预装：

- Node.js ≥ 22（`node:sqlite` 依赖，低于 22 会报 `ERR_UNKNOWN_BUILTIN_MODULE`）
- systemd 服务单元与 `/etc/<服务名>.env` 配置文件（含 `PORT`、`BANK_DB_FILE`、密钥）

生产环境参考配置：

```ini
# /etc/systemd/system/ai-banking-agent.service
[Service]
ExecStart=/usr/local/bin/node24 /opt/ai-banking-agent/server/index.js
EnvironmentFile=/etc/ai-banking-agent.env
Restart=always
RestartSec=3
ProtectSystem=full
ReadWritePaths=/opt/ai-banking-agent/data
```

## 6. 局域网访问（手机演示）

服务监听 `0.0.0.0:8787`，同一 Wi-Fi 下手机访问：

```text
http://<电脑局域网IP>:8787/
```

放行端口（Windows，管理员 PowerShell）：

```powershell
New-NetFirewallRule -DisplayName "ZhiYin 8787" -Direction Inbound -Protocol TCP -LocalPort 8787 -Action Allow -Profile Any
```

## 7. 数据与重置

- 数据文件：`data/bank.db`（SQLite，`state` + `ledger` 两张表）；
- 演示重置：页面右上角头像 →「重置演示数据」，或 `POST /api/reset`；
- 删除 `data/bank.db` 后重启会重新播种演示数据。

## 8. 环境变量

| 变量 | 作用 | 默认 |
|---|---|---|
| `PORT` | 服务端口 | `8787` |
| `BANK_DB_FILE` | SQLite 数据库文件路径 | `data/bank.db` |
| `BANK_DEMO_PIN` | 演示交易密码 / 短信验证码 | `123456` |
| `BANK_ADMIN_TOKEN` | 管理类接口口令（复核审批等） | 无（未设置时仅本机可调） |
| `AI_PROVIDER` | 大模型供应商，`siliconflow` 或 `deepseek` | 有 `SILICONFLOW_API_KEY` 时取 siliconflow，否则 deepseek |
| `SILICONFLOW_API_KEY` / `SILICONFLOW_MODEL` | 硅基流动密钥与模型名 | 模型默认 `Qwen/Qwen3-30B-A3B-Instruct-2507` |
| `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` | DeepSeek 密钥与模型名 | 无 |

> **密钥只放服务端**。前端拿到的 `js/core/config.local.js` 恒为 `window.__BANK_KEYS__ = {}`，
> 浏览器通过 `/api/ai/chat` 代理调用模型，永远接触不到真实 Key。
> 本地开发如需直连，可复制 `js/core/config.local.example.js` 为 `config.local.js` 自行填写，
> 该文件已在 `.gitignore` 中，不会被提交。

未配置任何大模型 Key 时，意图层会自动降级为规则引擎，全部演示流程仍可完整走通。
